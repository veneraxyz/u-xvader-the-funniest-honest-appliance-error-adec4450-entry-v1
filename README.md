Entry for [The Funniest Honest Appliance Error](https://make.fun/competitions/u-xvader-the-funniest-honest-appliance-error-adec4450) — a single line, at most 200 characters: the funniest honest error message from a household appliance, funny *and* true.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes exactly one line to `entry.txt` in the output directory.
